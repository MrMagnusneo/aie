# Ноутбуки

`01_eda_and_experiments.ipynb` показывает, как посмотреть сгенерированные self-play данные и метрики эксперимента.

Основной рабочий код находится не в ноутбуке, а в `src/`. Ноутбук нужен для защиты и краткого анализа:

- сколько примеров сгенерировано;
- какой баланс классов;
- какие метрики получила модель;
- чем модель отличается от baseline.
