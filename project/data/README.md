# Данные

В проекте не используется внешний датасет. Файл `generated_self_play.jsonl` создаётся командой:

```bash
python -m src.train --config configs/train.yaml
```

Каждая строка JSONL содержит один пример:

- `position_id` - идентификатор позиции в self-play партии;
- `fen` - позиция;
- `move_uci` - легальный кандидатный ход;
- `label` - 1 для хорошего хода, 0 для остальных;
- `reward` - численная reward-оценка;
- `san` - ход в шахматной SAN-нотации.

Данные синтетические, не содержат персональных данных и полностью воспроизводимы по `configs/train.yaml`.
